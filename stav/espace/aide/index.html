STAV user guide: SensorThings API Viewer

What is STAV?

STAV (SensorThings API Viewer) lets you view, understand and export environmental data published by SensorThings services.

With STAV you can:

  • Locate the measurement points on an interactive map
  • View the observations as graphs
  • Download the observations in CSV format
  • Share a specific context with a link
  • Compare several data series on the same graph

Navigating STAV

STAV is organised into several pages reachable from the navigation bar:

Entry point (list of available observatories)

The landing page lists all the available observatories.

Screenshot: landing page with the observatories

Home page

This page gives a summary of the observatory: location of the measurement points and various information (number of sensors, observed properties, time range).

Screenshot: observatory discovery page

Measurement points

Browse the list of measurement points (possibly with photos). From this page you can open a measurement point to get more information (number of sensors, observed properties, time range, visualisation link).

Screenshot: measurement points page

Data access

This is the main visualisation page. It lets you select one or more data series and display them as an interactive graph. You can zoom, download the data and share your context.

Screenshot: data access page

Metadata (optional)

This menu gives access to a metadata record.

Note: this menu only appears if the observatory provides a metadata record.

Metrology (optional)

This drop-down menu gives access to the technical monitoring tools intended for metrologists:

  • Sensor monitoring: status and history of the sensors
  • Field interventions log: journal of the interventions
  • Alerts: highlights the time series with outliers or missing data

Note: this menu only appears if the observatory has enabled metrological monitoring.

Using the graphs

Zoom on a period

Click and drag horizontally on the graph to zoom on a specific period. The graph is redrawn with the data of the selected range.

For some observatories, the level of detail adapts automatically to the zoom and to the screen size: the data go from a daily to an hourly aggregation, then to the raw values once the window is small enough.

Screenshot: zooming on a graph

Back to the full view

Click the "Reset zoom" button to go back to the display of the whole dataset. This button only appears while a zoom is active.

Overlay several series

On the "Data access" page, tick several series in the left-hand list. The curves are overlaid on the same graph, with a legend for each series.

Screenshot: graph with several overlaid series

Page navigation

When a dataset is very large and no aggregations are available, the data are split into pages. Arrows ◀ page ▶ appear above the graph. Click the arrows to navigate, or click the page indicator to type a page number directly.

Downloading data

Click the "Download" button to open the export window. Several options are available depending on the type of observatory:

  • All data (raw CSV): exports all the observations
  • Visible range (raw CSV): exports only the period displayed in the graph
  • Hourly aggregation: hourly mean of the values (if available)
  • Daily aggregation: daily mean of the values (if available)
Screenshot: download window
Sharing a context

Click the "Share" button to copy to the clipboard a link that reproduces exactly the visualisation context of the graph(s):

  • The selected series
  • The zoom level (if active)
  • The current page (if pagination is active)

Send this link to a colleague: opening it restores the same display configuration. The link is self-contained and does not require any login.

Glossary
Term Definition
Observatory Set of sensors deployed on a geographical site and available in a SensorThings service. An observatory groups one or more measurement points.
Measurement point Physical location where one or more sensors are installed (Thing in the SensorThings standard).
Observed property Physical quantity measured by a sensor: temperature, flow, pH, conductivity, etc. (ObservedProperty)
Sensor Measuring instrument (Sensor)
Data series Time series (Datastream) of an observed property (ObservedProperty) at a measurement point, by a sensor (Sensor). Example: "Water temperature at point A".
Observation Single value measured at a given time. Made of a date and a numerical result.
